# Spec: 报表与导出

**状态**: 路线图规划  
**日期**: 2026-04-29  
**相关模块**: 账单、还款、明细、权益、优惠、分析

## 目标

支持用户导出 CSV/Excel、月报和年报，把 WorldCredit 中的账单、还款、明细、权益使用和优惠使用数据带到表格工具中复盘、归档或二次处理。

## 用户故事

作为用户，我希望按月份导出账单和还款记录，以便做月度复盘。

作为管理员，我希望按成员、银行、卡片筛选导出，以便给家庭成员或具体卡片做对账。

作为用户，我希望导出账单明细，以便在表格工具中继续分类分析。

作为用户，我希望生成年度报告，以便复盘全年信用卡使用情况。

作为成员，我希望只能导出自己的数据，以便隐私边界一致。

## 范围

MVP 包含：

- CSV 导出。
- 按成员、银行、卡片、月份范围筛选。
- 导出账单、还款、账单明细、权益使用、优惠使用。
- 月报摘要。
- 年报摘要。

第二阶段包含：

- Excel 多 sheet 导出。
- 图表式 PDF 报告。
- 定时生成报告。

## 导出类型

### 明细 CSV

支持导出：

- 账单 CSV。
- 还款 CSV。
- 账单明细 CSV。
- 权益使用 CSV。
- 优惠使用 CSV。

### 月报

月报包含：

- 当月账单总额。
- 当月已还金额。
- 月末待还金额。
- 逾期账单数。
- 按成员/银行/卡片汇总。
- 消费分类汇总。
- 权益和优惠使用摘要。

### 年报

年报包含：

- 全年账单总额。
- 全年还款总额。
- 月度趋势。
- 最高消费月份。
- 逾期次数。
- 权益使用率。
- 优惠使用次数。
- 按成员/银行/卡片排名。

## 功能需求

### 导出入口

建议在分析页和账单页提供导出入口：

- 选择数据类型。
- 选择时间范围。
- 选择成员、银行、卡片。
- 选择格式：CSV，后续 Excel。
- 点击导出。

### CSV 格式

CSV 必须：

- 使用 UTF-8。
- 第一行为中文列名。
- 金额保留两位小数。
- 日期使用 `YYYY-MM-DD`。
- 空字段输出为空字符串。

### 文件命名

示例：

- `worldcredit-bills-2026-01_2026-04.csv`
- `worldcredit-payments-2026-04.csv`
- `worldcredit-annual-report-2026.csv`

## 数据与 API

建议新增：

- `getExportData(type, filters)`
- `buildCsv(rows, columns)`
- `downloadCsv(filename, content)`

如果后续服务端导出：

- `POST /exports`
- `GET /exports/:id`

第一版可以前端生成 CSV，避免新增后端任务。

## 权限

- 管理员可导出自己管理范围内的所有数据。
- 成员只能导出自己的数据。
- 导出接口必须复用现有权限查询或 RLS，不能只靠前端筛选。

## 边界情况

- 无数据时导出空 CSV，保留表头。
- 大量数据导出时需要 loading 状态。
- 跨币种不做汇率换算，保留原币种列。
- CSV 字段包含逗号、换行、引号时必须正确转义。
- 导出期间权限变更时以接口返回数据为准。

## 验收标准

- 用户可以按筛选条件导出账单、还款、明细、权益使用、优惠使用。
- CSV 可被常见表格工具正常打开。
- 管理员和成员导出范围符合权限。
- 月报和年报指标与分析页一致。
- 空数据、大量数据、特殊字符都有正确处理。
