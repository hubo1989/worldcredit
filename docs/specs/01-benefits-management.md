# Spec: 信用卡权益管理

**状态**: 已建模，界面不完整  
**日期**: 2026-04-29  
**相关表**: `benefits`, `benefit_usages`, `credit_cards`  
**相关 API**: `lib/api/benefits.ts`

## 目标

让管理员可以在卡片详情中完整维护信用卡权益，包括创建、编辑、删除权益，并让管理员和成员都能记录权益使用。当前系统已经支持权益表和使用记录，但 UI 主要停留在查看与“使用”按钮，缺少权益配置闭环。

## 用户故事

作为管理员，我希望为某张信用卡新增权益，以便记录该卡可用的机场贵宾厅、接送机、餐饮、保险、返现资格等权益。

作为管理员，我希望编辑权益名称、说明、额度、周期、重置月份和到期日，以便权益规则变化后系统数据保持准确。

作为管理员，我希望删除不再适用的权益，以便卡片详情只展示当前有效的权益。

作为用户，我希望看到权益已用次数、总额度、到期日和说明，以便判断还能不能继续使用。

作为用户，我希望记录一次权益使用，并可填写备注，以便家庭成员之间共享权益消耗情况。

## 范围

MVP 包含：

- 卡片详情页新增“添加权益”入口，仅管理员可见。
- 权益卡片新增编辑和删除入口，仅管理员可见。
- 权益使用按钮对管理员和成员可见。
- 记录权益使用时支持可选备注。
- 展示权益名称、说明、使用次数、总额度、周期、重置月份、到期日。
- 权益已用次数达到额度后禁用使用按钮。

不包含：

- 自动按周期重置使用次数。
- 权益价值估算。
- 权益跨卡共享。
- 外部银行权益同步。

## 功能需求

### 新增权益

管理员在卡片详情页点击“添加权益”，打开表单：

- 权益名称，必填。
- 权益说明，选填。
- 总额度 `quota`，必填，默认为 1，必须为正整数。
- 周期 `period`，必填，支持 `yearly`、`monthly`、`one_time`。
- 重置月份 `reset_month`，当周期为 `yearly` 时可填，范围 1-12。
- 到期日 `expiry_date`，选填。

提交成功后刷新卡片详情权益列表。

### 编辑权益

管理员可以修改已有权益的所有可编辑字段。编辑后保留既有使用记录，不重算历史数据。

### 删除权益

管理员删除权益前必须二次确认。确认文案需要说明该权益的使用记录会随权益一起删除，因为数据库使用 `ON DELETE CASCADE`。

### 记录权益使用

用户点击“使用”后打开轻量弹窗：

- 默认使用日期为今天。
- 备注可选。
- 提交后写入 `benefit_usages`。
- 成功后刷新 `used_count`。

当前 API `recordBenefitUsage` 只支持备注和默认日期；如需选择日期，需要扩展 API。

## 权限

- `admin`: 可创建、编辑、删除权益；可记录权益使用。
- `member`: 可查看自己卡片下的权益；可记录自己权益使用；不可维护权益定义。
- 未登录用户不可访问。

权限必须由 RLS 兜底：

- 管理员通过 `managed_by` 链路访问。
- 成员通过 `auth_user_id -> card_holders -> credit_cards -> benefits` 链路访问。

## 数据与 API

复用现有表：

- `benefits.id`
- `benefits.card_id`
- `benefits.name`
- `benefits.description`
- `benefits.quota`
- `benefits.period`
- `benefits.reset_month`
- `benefits.expiry_date`
- `benefit_usages.benefit_id`
- `benefit_usages.used_at`
- `benefit_usages.note`

建议 API 补充：

- `recordBenefitUsage(benefitId, input?: { used_at?: string; note?: string })`
- `getBenefitUsageCount(benefitId, periodWindow?)`，后续支持周期重置时使用。

## 边界情况

- 权益额度为 0 或负数时禁止提交。
- `reset_month` 超出 1-12 时禁止提交。
- 已过期权益仍展示，但使用按钮禁用，并标记“已过期”。
- 使用次数达到 `quota` 时禁用使用按钮。
- 删除权益前如果已有使用记录，需要明确提示。
- 成员访问不属于自己的权益时应被 RLS 拒绝。

## 验收标准

- 管理员可以在卡片详情页完成新增、编辑、删除权益。
- 成员看不到新增、编辑、删除入口。
- 管理员和成员都可以对有额度且未过期的权益记录使用。
- 已使用次数实时刷新。
- 到期、用尽、无权限状态都有明确 UI 反馈。
- 越权访问或写入在数据库层失败。
